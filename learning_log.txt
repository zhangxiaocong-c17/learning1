指针运算（Pointer Arithmetic）
在 C 语言里，数组名 cmd 本身就是一个指针，它代表这个数组的起始地址（也就是第 0 个房间的门牌号）。
假设用户输入了 -001，在内存里是这样的：
    内存地址：  0x100  0x101  0x102  0x103  0x104
    字符内容：  '-'    '0'    '0'    '1'    '\0'
    数组索引：  cmd[0] cmd[1] cmd[2] cmd[3] cmd[4]
cmd 就等于 0x100（指向 '-'）。
cmd[0] 就是 '-'。
在 C 语言里，给指针加 1，不是把地址数值加 1，而是“向后移动一个元素”。
cmd + 1 实际上是把地址变成了 0x101。

处理时间的方法：
0.time_t是一种变量格式 形如int 兼容性好（避免int在2038年溢出） 
1.time_t rawtime;//创建变量 每一个变量都自带一个内存里的地址
2.time(&rawtime);//将系统时间戳放进地址&rawtime对应的内存
    tip:这个函数也会同时返回时间的值 因此也可以time_t a = time(NULL); 但是此处不适用
3.localtime(&rawtime);//从这个地址读取时间戳 创建一个静态（函数内部）结构体 包含时分秒年月日星期等等 形式为tm_sec tm_hour等
4.struct tm *t = localtime(&rawtime); //创建一个名为t的指针指向这个静态结构体
5.t->tm_hour 相当于一个变量  可以被printf 等代码使用 也可以被用于判断 赋值 等等

初识结构体 
同一对象（如商品） 不同属性（价格 名称 ...） 数据类型不同 组合成 结构体
基本用法：
struct products
{
  char name[20];
  float price;
  ...
};//声明结构类型
struct products product[100];//定义100个结构变量product[i]
具体数据：变量product[1].price; 地址product[1].name;
注意 product[1].name 代表地址 为常量 对应一个数组product[1].name[20] 不可直接赋值 用strcpy
也就是说 结构体并不改变变量的属性
例： （定义char text[10] 和 float aaa）
text-->products.name    -->strcpy
aaa--> products.price   -->aaa = 1赋值
